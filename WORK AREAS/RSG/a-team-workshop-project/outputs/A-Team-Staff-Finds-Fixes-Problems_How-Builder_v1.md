# AN A-TEAM STAFF FINDS AND FIXES PROBLEMS — THE HOW BUILDER

*Turn the idea into steps they can run without you in the room.*

**Stage:** HOW (Planet Builder: WHY → WHAT → HOW → NOW)
**Lesson:** An A-Team Staff Finds and Fixes Problems
**Framework:** Name It. Own It. Make Room. *(three gates: Blind → Unowned → Buried)*
**Audience:** RSG pastors (Breaking 1000)

---

## THE STEPS
*The runnable process. First move first.*

**Step 0 — Pick one.** One real problem that's recurred for two or more cycles. Not your whole list. One.

**Step 1 — Name It.** Write the problem in one sentence, specific enough to be undeniable. Add a number if you have one.
*Vague:* "Our volunteer follow-up is weak." → *Named:* "We lose 3 of every 5 new volunteers in their first 60 days."

**Step 2 — Find the gate.** Which blocker has it jammed? **Blind** (nobody saw it / accepted it as normal), **Unowned** (everybody saw it, nobody owns it), or **Buried** (owned, but no time to touch it). Find the *first* locked gate.

**Step 3 — Own It.** Assign one name. A person, not a committee. The owner says out loud: "This is mine this cycle."

**Step 4 — Make Room.** Block the Quadrant-2 time on the owner's calendar this week. Then name what gets removed to create it. No removal, no room.

**Step 5 — Next move.** One concrete action the owner takes in the next 7 days. The first move toward the fix — not the whole fix.

**The skip that breaks it:** Step 4. Pastors name it and assign it, then never create the slack — so the fix dies in the tunnel. Second most-skipped: Step 2 — jumping to action before finding which door is actually locked.

**Done when:** the problem is named in one sentence, has one owner, has calendar room, and a dated next action. Four boxes filled. That's a rep.

---

## THE DEMO
*Show it, don't describe it.*

- Pull one volunteer on the call. Use their real stuck problem — live, on screen.
- Walk all five steps in under four minutes. Narrate the gate diagnosis out loud so the room hears the reasoning.
- Keep a pre-built worked example on screen (the volunteer-turnover one) so everyone has a format to copy.
- **One rep before they leave:** every pastor on the call fills the worksheet on one of their own problems during the segment. Nobody leaves with a blank sheet.

---

## THE SEQUENCE
*What has to happen before the next thing works.*

- **Order:** Name → Find the gate → Own → Make Room → Next move. Locked.
- **The shift point:** between *diagnosis* (Name + Gate) and *commitment* (Own + Room + Move). The first half is honesty. The second half is a decision.
- **Pause here:** right after Make Room. "What are you removing to create that time?" is where the honesty lives. Don't rush past it.
- **What can wait:** solving it. This process stops at the first move on purpose. The fix happens after the call, in the room they just made.
- **Pace:** fast through Name and Gate. Slow at Make Room.

## THE TOOLS
*What removes friction and turns a one-time effort into a habit.*

- **The one-page worksheet** (above) — printable, fillable, one per problem.
- **The Stuck Problem Log** — a running list of recurring problems to feed in over cycles, so you never stare at a blank page.
- **The calendar block** — the single friction-remover for Step 4. If it's not on the calendar, "Make Room" didn't happen.
- **The Cooldown trigger** — run this every 30-day Cooldown. Tying it to a rhythm you already have is what makes it a habit instead of a one-off.

---

## THE GUARDRAILS
*Where people go off the path. The minimum that still counts.*

- **Off the path:** assigning to a committee. → One name only. Shared ownership is no ownership.
- **Off the path:** naming the problem vaguely. → Force a specific or a number. If you can't measure it, you can't see it.
- **Warning sign:** the same problem shows up next Cooldown unchanged. That means Make Room never happened — it died in the tunnel.
- **If / then:** if there's no slack to give, then don't add the fix — remove something first. A fix with no room is a wish.
- **Minimum win:** one problem, named, owned, with room and a dated next move. Even one is a win. Don't run ten. Run one all the way through.

---

## PATHWAYS
*The ideal path, the costly detour, the rails for the new.*

- **Ideal path:** one problem per owner per cycle, run every Cooldown. Slow and complete beats fast and shallow.
- **Costly detour:** trying to fix everything at once. The tunnel comes right back, and nothing actually moves.
- **Skip a step, pay the price:** Skip *Name* → you solve the wrong thing. Skip *Own* → it's everyone's job, so it's no one's. Skip *Make Room* → it dies in the tunnel.
- **Shortcut for the experienced:** a Level 3 or 4 leader self-runs the worksheet and just reports the owner + date. **Rails for the new:** a Level 1 or 2 leader needs you to walk it with them the first time. *(See: The 4 Levels.)*

---

## MY ONE PROCESS

Pick one stuck problem.

Name it in a sentence. Find the gate it's jammed at. Give it one owner. Block the room to work it. Commit the next move with a date.

One problem, fully unblocked, beats ten problems half-noticed.
