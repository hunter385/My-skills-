# Project brief: Short-Form System

## What is this project?

The standing reference that defines how RSG short-form video gets built. HEIT (Hook → Explain → Illustrate → Teach) is the default per-video structure, replacing the old HOOK → BUILD → PAYOFF → INVITATION spine. Translated from the Martell Ultimate Content Playbook into RSG voice.

## Goal

One source of truth the short-form workflow pulls from every week: topic selection, script spine, voice/POV, cadence, metrics. Success = every short-form script gets built on HEIT, against a topic that passed the four tests, in Hunter's voice.

## Audience

Internal. Drives Hunter's five-videos-per-week short-form output. End viewers are pastors of stuck mid-sized churches (300–1,000 attendance) — and, increasingly, entrepreneurs in the same posture.

## Key constraints

- HEIT replaces HOOK → BUILD → PAYOFF → INVITATION as the default. Decided.
- The `/short-form-engine` skill still hardcodes the old structure in its SKILL.md. This reference overrides it on paper, but to make HEIT stick inside the skill itself, the skill must be edited in Settings > Capabilities. Flagged in memory.
- Five videos per week (current cadence). One video per week carries the ManyChat CTA.
